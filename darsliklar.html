🟢 10 ta asosiy dasturlash misoli

Har bir kartochka — bitta texnika. Kodini pastda ko'rasiz, tugmalarni bosib sinab ko'ring.

1-misol

Tugma bosilganda savol chiqishi

display:none / block orqali matnni yashirish va ko'rsatish

Savol: JavaScript qanday til?
Javob: U veb-sahifalarni interaktiv qiladigan dasturlash tili.
2-misol

Taymer (sekundomer)

setInterval() yordamida vaqtni sanash

0 soniya
3-misol

Matn razmerini o'zgartirish

input range orqali font-size ni real vaqtda o'zgartirish

Bu matn kattalashadi yoki kichraydi

4-misol

Fon rangini tanlash

input type="color" orqali dinamik stil o'zgartirish

5-misol

Modal (popup) oyna

Element ustiga qatlam sifatida chiqadigan oyna

6-misol

Akkordion (savol-javob ro'yxati)

Bosilganda ichidagi matn ochilib-yopiladigan blok

HTML nima?
HTML — sahifaning tuzilishini yaratuvchi belgilash tili.
CSS nima?
CSS — sahifaning tashqi ko'rinishini (rang, shrift, joylashuv) belgilaydi.
7-misol

Progress bar (jarayon chizig'i)

Tugma bosilganda foiz oshib boradigan chiziq

8-misol

Vazifalar ro'yxati (to-do)

Input orqali yangi elementlarni ro'yxatga qo'shish/o'chirish

    9-misol

    Sichqoncha ustiga borganda animatsiya

    CSS :hover va transition orqali effekt

    Menga sichqonchani olib keling
    10-misol

    Tab (bo'lim) almashtirish
